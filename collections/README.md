# Synthetic JSON collections

These seven JSON files mirror the application's seed-data collections and use synthetic development records. There are 20 patients, 20 doctors, 20 appointments, 20 medical records, 20 prescriptions, 20 invoices, and 42 users.

All users have the shared development password `123456`. The password is included as plain text here for import convenience. The application's Spring seed loader ignores the JSON `password` property and hashes `SEED_DEFAULT_PASSWORD` when creating users; set that environment variable to `123456` if you want the app's built-in seeding to use this shared password.

The appointment, medical-record, prescription, and invoice collections refer to people by email (`patientEmail` and `doctorEmail`) so the seed loader can resolve relationships. Primary keys are generated by the database. To use the built-in loader, copy these files into `backend/src/main/resources/seed-data/` and start with an empty database (each collection only seeds when its table is empty).

This is synthetic test data. Do not use the shared password or these records in production.
