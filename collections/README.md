# Synthetic JSON collections

These seven JSON files mirror the application's seed-data collections and use synthetic development records. There are 26 patients, 26 doctors, 26 appointments, 26 medical records, 26 prescriptions, 26 invoices, and 55 users.

All users have the shared development password `123456`. The password is included as plain text here for import convenience. The application's Spring seed loader ignores the JSON `password` property and hashes `SEED_DEFAULT_PASSWORD` when creating users; set that environment variable to `123456` if you want the app's built-in seeding to use this shared password.

The appointment, medical-record, prescription, and invoice collections refer to people by email (`patientEmail` and `doctorEmail`) so the seed loader can resolve relationships. Primary keys are generated by the database. These files are mirrored in `backend/src/main/resources/seed-data/`. The built-in loader inserts seed records that are missing from each collection and leaves existing records intact.

This is synthetic test data. Do not use the shared password or these records in production.
